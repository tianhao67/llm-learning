# 大模型基础

大语言模型（LLM）本质上是一个「预测下一个 token」的概率模型。训练时它读入海量文本，
学习在给定前文的条件下，下一个 token 出现的概率分布；推理时按这个分布采样或取最大值，
一个 token 接一个 token 地生成回答。

## token 与上下文窗口

token 是模型处理文本的最小单位，中文大约 1 个字对应 1 个 token，英文一个单词可能被拆成
多个 token。上下文窗口（context window）指一次请求里模型能「看到」的最大 token 数，
包括系统提示词、历史对话、检索到的资料和模型自己的输出。超出窗口的内容会被截断，
所以长文档问答必须先做检索和截取。

## temperature

temperature 控制采样的随机性。取 0 时模型几乎总是选择概率最高的 token，输出最稳定，
适合分类、信息抽取、结构化输出；取 0.7 到 1.0 时输出更发散，适合头脑风暴和文案写作。
同一段提示词在不同 temperature 下结果可能差别很大，做评测时必须固定该参数。

## 幻觉

幻觉指模型生成看似合理但事实错误的内容。常见原因有两个：训练数据里没有相关知识，
或者提示词没有提供足够依据。降低幻觉的常用手段包括：提供参考资料并要求引用来源、
要求模型在资料不足时明确说「不知道」、降低 temperature、以及用程序校验输出格式。

## 推理成本

推理成本主要由输入 token 数、输出 token 数和模型单价决定。上下文越长、输出越长，
成本越高；把整本书塞进提示词既贵又容易超出窗口。工程上通常用检索只取最相关的几段，
再配合缓存、限制输出长度来控制成本。
